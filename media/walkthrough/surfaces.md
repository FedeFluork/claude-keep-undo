## Pick your review surfaces

The extension can mark a change in several places at once. Showing all of them
together is noisy, so the defaults are deliberately narrow and everything is a
setting.

| Surface | Default | What it costs |
|---|---|---|
| Gutter bars + Quick Diff widget | **on** | A second set of bars beside Git's |
| Keep / Undo CodeLens rows | **diff only** | One row of height per change |
| Inline comment threads | off | A widget between your lines |
| Quick Fix entries (`Ctrl+.`) | **on, inside a change** | Two extra menu items |
| Explorer badge | **on the file** | — |
| Changes view count | **on** | — |
| Status bar entry | **when pending** | — |
| Source Control list | **on** | A second provider next to Git |

Three presets — **Minimal**, **Recommended** and **Everything** — set the whole
group at once, and every switch can still be changed on its own afterwards.

> Everything here is an ordinary VS Code setting: it can be set per project,
> travels with Settings Sync, and can be edited in the Settings editor under
> *Extensions › Keep / Undo for Claude Code*.
